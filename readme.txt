== Description ==

Omni Platform Newsletter provides a shared four-section content contract for
organizations that publish the same reviewed newsletter on the web, by email,
and as a two-sided printed letter.

Version 0.1 integrates Newspack Newsletters and Print My Blog. It does not
configure a sending provider, import contacts, or send campaigns.

== Installation ==

1. Install and activate Newspack Newsletters and Print My Blog.
2. Install and activate Omni Platform Newsletter.
3. Create a Newspack newsletter and insert the Omni duplex newsletter pattern.
4. Replace all placeholders with approved organization content.
5. Preview email and print exactly two Letter pages before sending or printing.
